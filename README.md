## 什么是静态住宅IP，和机房IP有什么区别

机房IP的ASN归属直接标着托管公司或云计算厂商，平台一查就知道你在用服务器。住宅IP的ASN归属是AT&T、Comcast、Frontier这类家庭宽带运营商，地理位置定位到真实居民区，从IPinfo到Scamalytics的各种IP数据库里都显示为ISP/Residential类型。

**静态住宅IP VPS的实现方式**：商家在美国真实租住民宅，向当地运营商申请家庭宽带入户，把服务器放在那个房子里运行。你买的VPS拿到的IP，就是从那条家庭宽带的IP池里分配出来的独享静态地址。这个IP一旦分配就固定了，不会每天变动，适合需要稳定身份标识的业务场景。

和动态NAT（多人共享同一出口IP、IP每天自动更换）对比，静态住宅IP的核心优势是"一个账号对应一个固定IP"，模拟不同的真实用户，而且账号活跃历史稳定，风控评分更高。
